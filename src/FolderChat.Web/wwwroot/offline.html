FolderChat isn't running

The app is a window onto FolderChat's server, which runs on this computer. Start it, then try again:

  • From the code: dotnet run --project src/FolderChat.Web
  • From Visual Studio or Rider: run the FolderChat.Web project.

If you start FolderChat at a different address or port than when you installed the app, open that address in your browser and install it again.
